# Bouquets

Animated ASCII-art baby's breath bouquets, drawn in the browser with a canvas.

Open `index.html` in any browser. Six versions, switchable from the tabs (or link straight to one with `#plush`, `#rainbow`, `#midnight`, `#strawberry`, `#lavender`, `#sunshine`):

- **plush** – dusty pastels, oatmeal and sage wrap, a round penguin in a pink scarf
- **rainbow** – bright rainbow florets, blush and lilac wrap
- **midnight** – blues and silver whites with a crescent moon
- **strawberry milk** – pinks and creams in pink gingham, penguin in a red scarf
- **lavender** – purples in kraft paper
- **sunshine** – yellows in sky-blue paper, penguin in a yellow scarf

Hover to ruffle the flowers, tap for sparkles, and hit **re-arrange** for a new layout.

Tap the penguin for a surprise: a sealed envelope drops in, and opening it reveals a heart-shaped love letter with a different sweet message each time.
